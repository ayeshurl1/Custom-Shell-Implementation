Custom Shell (C++) - Project 3 (Full Package)

Files:
- src/shell.cpp : C++ source code for the custom shell
- bin/myshell : compiled binary (after you compile)
- docs/ : contains report DOCX and PDF
- screenshots/ : demo screenshots

Compile:
g++ -O2 -std=c++17 src/shell.cpp -o bin/myshell

Run:
./bin/myshell
Type commands like: echo hello
Piping example: ls | head -n 5
Type 'exit' to quit.
